# 策划实现说明

依据上传的《代号：盗墓》《需求列表》《游戏机制》《游戏说明》《视觉设计》及各类配置表，对现有项目补齐探索—战斗—收集—交易—机关—逃生流程，使用上传的地图、角色、怪物、物品、界面与图标素材；原音频与新增原创短音保留。

## 文档冲突与未定义数值

- **键位**：《游戏说明》写 M 背包，《需求列表》和视觉草图写 B 背包、M 小地图；采用后者，与原项目操作一致。
- **移速/攻速增益名称**：buff/shop 表的 3002、3003 引用了互换的 lang 名称。保留各 ID 的效果，3002 移速 +20% 对应“鬼影疾行”，3003 攻速 +20% 对应“疾如鬼手”。
- **坐标单位/移速**：monster 表每速度单位为 20px/s、每距离单位为 32px，手枪射程 160px。按后续用户要求，主角保留第一版场景导出的 500px/s，host 表的 speed 不再覆盖它；移速增益与中毒仍基于当前场景值计算。
- **中毒**：status 表的 `1,3` 按文字解释为移速减少 1 单位（20px/s）、攻击减少 3 点。未买增益时主角速度 500→480px/s。机制文档还要求毒持续掉血，但没有提供该项数值；默认每秒 10 点，通过 `State.PoisonDamagePerSecond` 可调。
- **状态时长**：文档以止血/解毒为清除途径，没有指定自动结束时间，默认持续到治疗；`BleedDuration`、`SlowDuration` 为 0 表示无限，正数可启用限时状态。
- **流血概率**：monster 表写利爪攻击使玩家流血，机制文档写概率触发。提供 `SharpZom.BleedChance`，默认 1，与表中必触发描述一致，可调为小于 1 的概率。
- **宝箱补给**：2004 掉落表只列财宝，而机制文档要求获得子弹/药品，且子弹须有可持续来源。保留财宝权重，每箱默认额外给 12 发备用子弹和随机一种消耗品 1 份。通过 `Treasure.BonusBullets`、`BonusSupplies` 配置，未杜撰原表行或改变财宝概率。
- **初始物资/库存**：策划未定义，保留原工程的 1000 财宝、6 发装填、20 发备用、2 药品、3 绷带、3 解毒剂、0 碎片；每种商品库存默认 10。主角血量按 host 表改为 1000。
- **子弹购买单位**：按最新需求每组 10 发，数量选择和库存均按组计算，保留 shop 表的 600 财宝购买单价，即 600 财宝/组；后备与弹膛严格分开，只有换弹转移。
- **动画/音乐**：主角动作使用上传开火与受伤立绘，加后坐、枪口闪光、红闪；僵尸使用上传普通/攻击立绘，加出现升起渐显、步态、出手、红闪后仰、倒地渐隐。所有动画只改变立绘，不移动碰撞体。流血/中毒独立短音由 `tools/create_status_audio.py` 生成，分别为轻心跳/气泡音。开始界面循环现有 `BGM_begin.ogg`，成功/失败新增原创循环旋律 `BGM_victory.wav` / `BGM_defeat.wav`，一次性结算音效仍走 Sfx。
- **计分**：仅指定“携带财宝越多分越高”，因此得分直接等于逃出时财宝数量，不添加未定义奖励。
- **视觉**：按后续用户要求恢复第一版背包、商店底图、格子、加减框和美术按钮，保留物资及增益购买逻辑。四种 buff 使用上传的攻击、移速、攻速、暴击独立图标，并显示名称和数值。暗箭图像由图像生成工具创建，原始透明 PNG 为 `bin/projectiles/trap_arrow.png`。

## 数据调整

`GameData` 和掉落组件按进程缓存 JSON。编辑数据后重启运行即可生效；调整 C# 需重新构建。JSON 为运行时数据源，上传的 CSV 为同一配置的表格版本。`item.json` 额外保留原工程必需的 `location` 绑定。

主菜单名称改为“墓下”。六种僵尸均由对应 `MonsterId` 关联 monster 表，地图扩充至十六口棺材（3 小僵尸、2 瞬移、2 利爪、3 毒箭、3 弓箭、3 重型）与十二块危险机关（6 地刺、6 暗箭）。棺材、四个宝箱均有实体碰撞，布局保留入口至出口的可通行路线。

## 验证与仍需试玩的内容

自动回归运行真实场景，除逻辑断言外，也验证实际碰撞伤害、子弹命中、场景切换及窗口视口边界。另使用软件 OpenGL 渲染复查主玩法、背包、商店、设置和交互确认画面。构建存在原工程 `soulpiece` / `debuff` 小写类型名称的 CS8981 警告。

单局 10–20 分钟的目标、敌人分布、补给数量、物价、恐怖感与音量舒适度仍需人工试玩调平衡。软件渲染检查不等同于 Windows D3D12 或真实 GPU 的性能验证；未验证 Windows/Android 导出。现有素材没有专门的地刺展开音效，地刺使用踩机关音效。
