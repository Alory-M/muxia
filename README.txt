现在你要做一个简易的背包系统

你需要先编写一个功能,在游戏中按下B会让packsys的visibility为true,并使其控件可交互(初始状态为不可见不可交互),再次按下则又变为不可见不可交互

第二,编写道具可视功能,在此路径(F:\godot3\demo\枪械预设\bin\pack)下有三种道具,分别为绷带,解毒剂和药品,你需要编写packsys的脚本令packsys的控件可见可交互时显示你的道具.实现方法为,先去查询剩余道具数量(访问player下的pack子节点),顺序根据supplykind的枚举顺序决定,当道具数量大于0时,在packsys下属的button节点中通过image显示图标(我已经创建好了),虽然我已经预设好了图标,但你仍需编写一个函数,根据道具数量灵活显示图标,以下是道具对应的图标{_drugCounter:药品.png,_bandageCounter:绷带.png,_antidoteCounter:解毒剂.png},并且button需要记住当前它所对应的道具

第三,你需要编写一个脚本,当以上图标对应的button被按下时,弹出ask界面(初始为不可见不可交互),让用户选择是否使用(界面我已经预设),label根据button传递的道具信息显示"是否使用xx",xx为button传递过来的道具名称

第四,需要编写道具使用系统,当ask中的yes被按下时,对应道具-1,并执行clear脚本中对应的功能,no被按下时不执行任何消耗,ask重新变为不可见不可交互
